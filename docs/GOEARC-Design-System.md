GOEARC Design System
Project Vision

The GOEARC platform exists to provide a calm, trustworthy, and welcoming digital experience for families, caregivers, donors, volunteers, and community partners.

The website should feel less like a traditional charity website and more like entering a peaceful retreat.

Every interaction should reinforce the organization's mission of supporting neurodivergent individuals and their families.

Core Design Principles
1. Hope First

Every page should inspire hope before presenting information.

2. Simplicity

Never overwhelm parents with information.

Complex topics should be broken into small, readable sections.

3. Calmness

Generous spacing.

Soft colours.

Gentle animations.

No visual clutter.

4. Trust

Everything should communicate professionalism.

Clear navigation.

Clear pricing.

Clear registration.

Transparent charity information.

5. Accessibility

Every page must be usable for

parents under stress
neurodivergent users
keyboard users
screen readers

Component Philosophy

Every component must have

one responsibility
one visual style
one reusable implementation

Never duplicate components.

UX Principles

Never make a parent wonder

"What do I do next?"

Every page must clearly guide users toward the next action.

Registration Philosophy

Registration should feel supportive.

Never overwhelming.

Start small.

Gather detailed clinical information later.

Performance Goal

Every page should feel fast.

Lazy-load large media.

Optimize images.

Keep animations lightweight.

Accessibility Goal

WCAG AA compliance.

Keyboard navigation.

Meaningful labels.

High contrast.

Visible focus states.
